# Workana · Talento verificado para tu problema

Prototipo de la nueva experiencia de contratación de Workana: eliges el problema que quieres resolver, ves el talento verificado que te proponemos y completas un diagnóstico de 4 pasos.

Ver online: https://matibrenta.github.io/workana-contratar/

Es un prototipo: el formulario no envía datos, los horarios de la agenda y los perfiles son de ejemplo.
